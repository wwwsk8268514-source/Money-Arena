M-Pesa Setup

  1. Create/login to your Safaricom Daraja developer account.
  2. Create a sandbox app and obtain Consumer Key and Consumer Secret.
  3. Use the sandbox test Shortcode and Passkey supplied by Daraja.
  4. Copy backend/.env.example to backend/.env.
  5. Set PUBLIC_BASE_URL to a publicly reachable HTTPS URL for callbacks.
  6. Run npm install and npm start inside the backend folder.
  7. Test checkout with the Daraja sandbox before requesting production go-live.

Security: never paste Consumer Secret or Passkey into checkout.html or other browser JavaScript.
